# Instrucciones de trabajo

## Fuente oficial

- Este es el único repositorio activo de la web de Congelados Romasil.
- La producción oficial es `https://congeladosromasil.cl`, alojada en Vercel.
- El repositorio oficial es `lbarrosoficina/romasil-familia-que-rinde`, rama `main`.
- Los archivos publicables están directamente en la raíz de este repositorio.
- No usar `tienda-congelados`, `Congelados-Romasil` ni carpetas bajo `Propuestas/Anteriores` como fuente de producción.

## Cambios y publicación

- Acumular y probar localmente los cambios solicitados.
- No crear commits ni subir cambios a GitHub hasta que el usuario autorice expresamente la publicación.
- Antes de publicar, resumir el lote completo y comprobar que no incluye secretos.
- Después de publicar, verificar el despliegue de Vercel y el dominio principal.
- Mantener `docs/WEB.md` actualizado cuando cambien la arquitectura, el dominio, el repositorio o el procedimiento de publicación.

## Correo

- Para correo, reenvíos, Gmail, Cloudflare Email Routing y Resend, consultar `docs/CORREO.md`.
- No mezclar cambios de correo con cambios de la web si el usuario no lo pidió.
- Nunca guardar credenciales, claves API ni códigos de verificación.
